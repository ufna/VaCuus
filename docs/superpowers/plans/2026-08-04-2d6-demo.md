# 2d6demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/w/Unreal/Demo2d6` — a standalone UE 5.8 C++ project that consumes VaCuus exactly as an external buyer receives it, and renders three animated screens from the client's Photoshop comps over a live 3D scene, driven by a C++ mock simulation.

**Architecture:** The plugin is dropped in as a `BuildPlugin` **source** package under `Plugins/VaCuus`. UI is TSX over the VaCuus preact facade, built by the plugin's own `vacuus` CLI into `Content/DevUI/2d6/`. A `UWorldSubsystem` simulates ship state and pushes it once per frame through `UVaCuusView::UpdateModel`; the UI polls per-domain revision counters in `requestAnimationFrame` and re-reads only what moved. All motion is `transform`/`opacity`/decorator interpolation so it stays off RmlUi's relayout and geometry-rebuild paths.

**Tech Stack:** UE 5.8.1 (source build at `/w/Unreal/UnrealEngine`) · VaCuus (RmlUi 6.x, quickjs-ng) · TypeScript/TSX + preact 10.29.7 via `@vacuus/preact` · esbuild · Python 3 + `psd-tools` for asset extraction · Orbitron / Rajdhani / Michroma (OFL).

**Spec:** `docs/superpowers/specs/2026-08-04-2d6-demo-design.md`

## Ground rules for every task

- **No editor may be running while you build.** `pgrep -a UnrealEditor`, then kill **by PID**. Never `pkill -f <pattern>` — the pattern matches your own bash wrapper and kills the shell.
- **`-ExecCmds` splits on COMMAS, not semicolons**, and swallows every argument after it; the launcher re-appends `-game` at the end. **Always end the value with a comma.**
- Read test counts from `Saved/Logs/<Project>.log`, not stdout.
- Launch editors detached (`setsid nohup … & disown`) with an **absolute** `.uproject` path.
- Commits in this plan are to **`/w/Unreal/Demo2d6`** (a new repo). Do **not** commit to `/w/Unreal/VaCuus` — file a bead instead.
- Track work with `bd`, not markdown TODO lists.
- **`overflow` CLIPS NOTHING IN THIS PROJECT, and fails silently.** `.stage` carries the
  fit-to-view `transform`, and `ElementUtilities.cpp:174` sets `disable_scissor_clipping`
  unconditionally whenever a transform is active on the clipping chain, while the clip mask
  meant to replace it is **skipped in v1** (`VaCuusReplayRenderer.cpp:741-753`). So the
  original clipping is off and its replacement never lands. Proven in Task 8: a 40×14
  `overflow: hidden` box with a 200×14 child rendered the child at its full width.
  **Design so nothing needs clipping** — delete nodes you do not show, clamp values in JS,
  and size containers to their content. That is also what the perf guide prefers
  independently ("clipping is not free — clipped scrollback still records"). An `overflow`
  declaration left in a sheet is inert and misleading; the ones that survive in this plan
  are harmless only because their content already fits. Filed as `VaCuus-buk` (P1).

## Task 1: Prove `@font-face` works (risk R1)

Nothing in the VaCuus repo has ever loaded a font through `@font-face`, and there is **no public C++ font API** — `Rml::LoadFontFace` is called only from `Source/VaCuus/Private/VaCuusEngine.cpp:138-153`. If this path is broken the whole comp falls back to LatoLatin, so it is proven before any layout exists. Run it in `/w/Unreal/VcHost`, which already builds.

Grammar, read at `Source/ThirdParty/RmlUi/Source/Core/StyleSheetParser.cpp:294-330, :525-564`:
- required: `font-family` (string), `src` (comma-expanded **bare paths — no `url()`**)
- optional: `font-weight` (`all|normal|bold|<number>`, default `all`), `font-style` (`normal|italic`), `-rmlui-fallback-face`, `-rmlui-face-index`
- `src` is handed to `Rml::LoadFontFace` **verbatim** — it does **not** go through `JoinPath` the way `<link>` and `<script src>` do, so whether it is document-relative or root-relative is unknown. The proof tests both.

**The vehicle, and why it is a temporary edit rather than a new document.** *No VaCuus
console command accepts a document path* — every demo hardcodes its own (`vacuus.UMGDemo`
is `GDocumentVfsPath = "m1_hud.rml"` at `VaCuusUMGWidget.cpp:294`, registered as a
zero-argument `FAutoConsoleCommand` at `:400`; the same is true of `M1HUD`, `M2Demo`,
`M5Demo`, `RefHud` and the rest). So a brand-new `fontproof.rml` could not be displayed
at all. Instead, temporarily edit a document the engine already knows how to show.

`/w/Unreal/VcHost/Plugins/VaCuus` is a **git clone** (verified clean at `9895a51`), so
every edit below is reverted with one `git checkout`. VcHost is already built, so this
proof needs **no compile at all** — it is minutes, not the 10 minutes a project build costs.

`m2_demo` is the target: a plain document with no script bundle, and the edit adds **no
elements**, so the rect counts `vacuus.M2Demo.Rects` asserts are untouched.

```cpp
class UVaCuusWidget;
class UVaCuusView;

UCLASS()
class DEMO2D6_API ADemo2d6HudActor : public AActor
{
	GENERATED_BODY()

public:
	ADemo2d6HudActor();

	virtual void BeginPlay() override;
	virtual void EndPlay(const EEndPlayReason::Type Reason) override;

	/** Show an arbitrary DevUI document. This is the hook every later task uses. */
	UFUNCTION(BlueprintCallable, Category = "2d6")
	void ShowDocument(const FString& VfsPath);

	UVaCuusView* GetView() const;

private:

	UPROPERTY()
	TObjectPtr<UVaCuusWidget> Widget;

	TSharedPtr<SWidget> HeldSlate;
```

`Source/Demo2d6/Demo2d6Hud.cpp`:

```cpp
#include "Demo2d6Hud.h"

#include "Engine/GameInstance.h"
#include "Engine/GameViewportClient.h"
#include "GameFramework/PlayerController.h"
#include "HAL/IConsoleManager.h"
#include "VaCuusUMGWidget.h"
#include "VaCuusView.h"

ADemo2d6HudActor::ADemo2d6HudActor()
{
	PrimaryActorTick.bCanEverTick = true;
}

void ADemo2d6HudActor::BeginPlay()
{
	Super::BeginPlay();

	UGameInstance* GI = GetGameInstance();
	UGameViewportClient* Viewport = GI ? GI->GetGameViewportClient() : nullptr;
	if (!Viewport)
	{
		return;
	}

	Widget = NewObject<UVaCuusWidget>(GI);
	// Loading is deferred so Task 12 can bind its model first: RmlUi resolves
	// data-model exactly once, in Element::SetParent, so BindModel must precede
	// LoadDocument. The command queue is FIFO from one producer, which is what
	// carries that ordering across the thread boundary.
	Widget->bAutoLoadDocument = false;

	HeldSlate = Widget->TakeWidget();          // creates the view
	Viewport->AddViewportWidgetContent(HeldSlate.ToSharedRef(), /*ZOrder=*/100);

	// NOT A NICETY. Under the default FInputModeGameOnly the viewport holds mouse
	// capture, so FSlateApplication routes every pointer event straight to the captor
	// and never runs a hit test — no input reaches the UI at all.
	if (APlayerController* PC = GI->GetFirstLocalPlayerController())
	{
		FInputModeGameAndUI Mode;
		Mode.SetLockMouseToViewportBehavior(EMouseLockMode::DoNotLock);
		Mode.SetHideCursorDuringCapture(false);
		PC->SetInputMode(Mode);
		PC->SetShowMouseCursor(true);
	}
}

void ADemo2d6HudActor::EndPlay(const EEndPlayReason::Type Reason)
{
	if (UGameInstance* GI = GetGameInstance())
	{
		if (UGameViewportClient* Viewport = GI->GetGameViewportClient())
		{
			if (HeldSlate.IsValid())
			{
				Viewport->RemoveViewportWidgetContent(HeldSlate.ToSharedRef());
			}
		}
	}
	if (Widget)
	{
		Widget->ReleaseSlateResources(/*bReleaseChildren=*/true);
	}
	HeldSlate.Reset();
	Super::EndPlay(Reason);
}

UVaCuusView* ADemo2d6HudActor::GetView() const
{
	return Widget ? Widget->GetView() : nullptr;
}

void ADemo2d6HudActor::ShowDocument(const FString& VfsPath)
{
	if (Widget)
	{
		// LoadDocument also updates DocumentPath, so a Slate rebuild returns here.
		Widget->LoadDocument(VfsPath);
	}
}

namespace
{
ADemo2d6HudActor* FindHud(UWorld* World)
{
	for (TActorIterator<ADemo2d6HudActor> It(World); It; ++It)
	{
		return *It;
	}
	return nullptr;
}

FAutoConsoleCommandWithWorldAndArgs GCmdUI(
	TEXT("demo2d6.UI"),
	TEXT("demo2d6.UI <vfs-path> — show any DevUI document, e.g. demo2d6.UI 2d6/2d6.rml"),
	FConsoleCommandWithWorldAndArgsDelegate::CreateLambda(
		[](const TArray<FString>& Args, UWorld* World)
		{
			if (ADemo2d6HudActor* Hud = World ? FindHud(World) : nullptr)
			{
				Hud->ShowDocument(Args.Num() > 0 ? Args[0] : TEXT("2d6/2d6.rml"));
			}
		}));
}	 // namespace
```

- [ ] **Step 2: Write the extractor**

`Tools/extract_psd.py`:

```python
#!/usr/bin/env python3
"""PSD -> PNG asset extraction, driven by Tools/assets.json.

Layers in these comps are mostly hidden alternates, so every export forces the
target group visible before compositing. Output is written at the comp's own
resolution and downsampled by the caller-supplied scale, because the comps are
1920x1080 * 2.3887.
"""
import json, os, sys
from psd_tools import PSDImage

SCALE = 2.3887  # comp 4586x2580 -> 1920x1080 base


def find(layers, name):
    for l in layers:
        if l.name == name:
            return l
        if l.is_group():
            r = find(l, name)
            if r:
                return r
    return None


def show(layer):
    layer.visible = True
    if layer.is_group():
        for c in layer:
            show(c)


def export(psd, spec, outdir):
    node = psd
    for part in spec["path"]:
        node = find(node, part)
        if node is None:
            print("MISS %s -> %s" % (spec["out"], part))
            return False
    show(node)
    img = node.composite(force=True).convert("RGBA")
    if spec.get("scale", True):
        w = max(1, round(img.width / SCALE))
        h = max(1, round(img.height / SCALE))
        img = img.resize((w, h))
    path = os.path.join(outdir, spec["out"])
    os.makedirs(os.path.dirname(path), exist_ok=True)
    img.save(path)
    print("OK   %-40s %dx%d" % (spec["out"], img.width, img.height))
    return True


def main():
    manifest = json.load(open(sys.argv[1]))
    outdir = sys.argv[2]
    ok = miss = 0
    for psd_path, specs in manifest.items():
        psd = PSDImage.open(psd_path)
        for spec in specs:
            if export(psd, spec, outdir):
                ok += 1
            else:
                miss += 1
    print("\n%d exported, %d missed" % (ok, miss))
    sys.exit(1 if miss else 0)


if __name__ == "__main__":
    main()
```

```tsx
    const v = vacuus.view;
    if (!v.width || !v.height) return;
    const s = Math.min(v.width / BASE_W, v.height / BASE_H);
    // Write conditionally. ElementStyle::SetProperty dirties the element whether or not
    // the value changed (ElementStyle.cpp:606-618), so an ungated write restyles every
    // frame for nothing — measured 138 writes vs 1 over the same window.
    //
    // What it does NOT buy, on this property: a publish. `transform` is registered
    // forces_layout=false (StyleSheetSpecification.cpp:393, and rcss-matrix.md:98), so
    // rewriting an identical transform relayouts nothing, releases and remakes no
    // geometry, and hashes the same — the measured Replay count was 1 either way. The
    // gate is still the project rule and does buy a publish on any layout- or
    // geometry-affecting property; just don't attribute that to this line.
    const next = `scale(${s.toFixed(4)})`;
    if (stage.getAttribute('data-scale') !== next) {
        stage.setAttribute('data-scale', next);
        stage.style.transform = next;
    }
}

function Root() {
    return (
        <div id="stage" class="stage">
            <Catalog />
        </div>
    );
}

render(<Root />, document!.getElementById('mount')!);

// THREE drivers, and the rAF one is not redundant. At module scope `vacuus.view` is
// often still 0x0, so the immediate call can no-op; and `AutoShot N` fires after ~N
// RECORDED frames — well inside 250 ms — so a screenshot run driven only by the
// interval photographs the stage UNSCALED. rAF closes that window; the interval then
// keeps catching genuine resizes, for which the facade provides no event.
applyScale();
requestAnimationFrame(applyScale);
setInterval(applyScale, 250);
```

```cpp
void UDemo2d6SimSubsystem::StepState(FDemo2d6State& S, float Dt, bool bFiring)
{
	bool bShipChanged = false;
	bool bTurretsChanged = false;

	// Heat: rises while firing, decays otherwise, always clamped to [0, cap].
	const float HeatBefore = S.Ship.Heat;
	if (bFiring)
	{
		S.Ship.Heat += HeatPerShot * ShotsPerSecond * Dt;
	}
	S.Ship.Heat -= HeatDecayPerSecond * Dt * (bFiring ? 0.35f : 1.f);
	S.Ship.Heat = FMath::Clamp(S.Ship.Heat, 0.f, S.Ship.HeatCap);
	bShipChanged = !FMath::IsNearlyEqual(HeatBefore, S.Ship.Heat);

	for (FDemo2d6Turret& T : S.Turrets)
	{
		if (T.State == EDemo2d6TurretState::Reload)
		{
			T.ReloadRemaining -= Dt;
			if (T.ReloadRemaining <= 0.f)
			{
				T.Ammo = T.AmmoMax;
				T.State = EDemo2d6TurretState::Ready;
				T.ReloadRemaining = 0.f;
				bTurretsChanged = true;
			}
			continue;
		}
		if (bFiring && T.State == EDemo2d6TurretState::Ready && T.Ammo > 0)
		{
			// One shot per step is enough for a demo; the visible behaviour is the
			// drain-and-reload cycle, not a ballistics model.
			T.Ammo = FMath::Max(0, T.Ammo - 1);
			bTurretsChanged = true;
			if (T.Ammo == 0)
			{
				T.State = EDemo2d6TurretState::Reload;
				T.ReloadRemaining = ReloadSeconds;
			}
		}
	}

	if (bShipChanged) { ++S.ShipRevision; }
	if (bTurretsChanged) { ++S.TurretsRevision; }
}

void UDemo2d6SimSubsystem::Tick(float Dt)
{
	if (State.Sections.Num() == 0)
	{
		ResetState(State);
	}
	FireTimer += Dt;
	const bool bFiring = FMath::Fmod(FireTimer, 9.f) < 4.5f;   // fire in bursts
	StepState(State, Dt, bFiring);
}

void UDemo2d6SimSubsystem::SetScreen(const FString& Screen)
{
	if (State.Screen != Screen)
	{
		State.Screen = Screen;
		++State.UiRevision;
	}
}

void UDemo2d6SimSubsystem::SetHeat(float Value)
{
	State.Ship.Heat = FMath::Clamp(Value, 0.f, State.Ship.HeatCap);
	++State.ShipRevision;
}

void UDemo2d6SimSubsystem::DamageSection(const FString& SectionId, float Amount)
{

	{
		if (Sec.Id == SectionId)
		{
			Sec.Integrity = FMath::Clamp(Sec.Integrity - Amount, 0.f, 100.f);
			++State.SectionsRevision;
			return;
		}
	}
}

	{
		FDemo2d6Contact C;
		C.Id = NextContactId++;
		C.X = FMath::FRandRange(-1.f, 1.f);
		C.Y = FMath::FRandRange(-1.f, 1.f);
```

```cpp
void ADemo2d6HudActor::HandleJsEvent(FName Name, const TArray<FVaCuusJsKeyValue>& Payload)
{
	UDemo2d6SimSubsystem* Sim = GetWorld() ? GetWorld()->GetSubsystem<UDemo2d6SimSubsystem>() : nullptr;
	if (!Sim)
	{
		return;
	}

	auto Str = [&Payload](const TCHAR* Key) -> FString
	{
		for (const FVaCuusJsKeyValue& KV : Payload)
		{
			if (KV.Key == Key)
			{
				return KV.Value.String;
			}
		}
		return FString();
	};

	if (Name == TEXT("nav"))
	{
		Sim->SetScreen(Str(TEXT("screen")));
	}
	else if (Name == TEXT("select_slot"))
	{
		Sim->SelectSlot(Str(TEXT("id")));
	}
	else if (Name == TEXT("turret_action"))
	{
		Sim->PushNotice(TEXT("info"), FString::Printf(TEXT("ORDER: %s"), *Str(TEXT("action"))));
	}
}
```

`FVaCuusJsValue` is a tagged union — `Kind` ∈ {`Null`,`Bool`,`Number`,`String`} plus
`bBool`/`Number`/`String`. The payload is **flat**: `bool`/`number`/`string` cross and
everything else — nested objects, arrays, functions — is **skipped, not stringified**.

```ts
/**
 * vacuus.model() mints a fresh object per call and has NO subscription — polling is
 * the only read path. Reading every leaf each frame would be pure waste, so this
 * polls six integers and re-reads a domain only when its revision moves.
 */
const M = vacuus.model('sim');   // mint ONCE: vacuus.model(x) !== vacuus.model(x)

export type Domain = 'ship' | 'sections' | 'turrets' | 'slots' | 'contacts'
                   | 'notices' | 'ui';

const REV_PATH: Record<Domain, string> = {
    ship:     'ShipRevision',
    sections: 'SectionsRevision',
    turrets:  'TurretsRevision',
    slots:    'SlotsRevision',
    contacts: 'ContactsRevision',
    notices:  'NoticesRevision',
    ui:       'UiRevision',
};

const lastRev: Partial<Record<Domain, number>> = {};

/**
 * Subscribers are KEYED, and a repeat key replaces rather than appends. Screens call
 * subscribe() from inside their render body, which runs on every re-render — an
 * append-only list would grow without bound and fan every revision bump out to a
 * pile of stale closures.
 */
const subs = new Map<string, { domain: Domain; fn: () => void }>();

export function subscribe(domain: Domain, key: string, fn: () => void) {
    subs.set(key, { domain, fn });
}

export function num(path: string, fallback = 0): number {
    const v = M.get(path);
    return typeof v === 'number' ? v : fallback;
}

export function str(path: string, fallback = ''): string {
    const v = M.get(path);
    return typeof v === 'string' ? v : fallback;
}

export function bool(path: string): boolean {
    return M.get(path) === true;
}

export function count(arrayPath: string): number {
    const v = M.get(`${arrayPath}.size`);
    return typeof v === 'number' ? v : 0;
}

/** Call once per rAF. Returns the set of domains that changed this frame. */
export function poll(): Domain[] {
    const moved: Domain[] = [];
    for (const d of Object.keys(REV_PATH) as Domain[]) {
        const r = num(REV_PATH[d], -1);
        if (lastRev[d] !== r) {
            lastRev[d] = r;
            moved.push(d);
        }
    }
    if (moved.length > 0) {
        subs.forEach((s) => {
            if (moved.indexOf(s.domain) >= 0) s.fn();
        });
    }
    return moved;
}
```

Path grammar reminders: `Killfeed[0].Killer` for a struct-array leaf and `Killfeed.size` for the count; a miss returns `null` with one warning per (model, path).

## Model bridge facts — settled by observation in Task 12, read before Tasks 14–17

**1. A `uint8`-backed `UENUM` crosses as its authored NAME STRING, not as a number.**
Observed: `vacuus.model('sim').get('Slots[0].Category')` → `"Main"`, `typeof === "string"`.
The plugin binds every enum as `EVaCuusFieldKind::Enum`, documented as "ONE variable
holding the name string" (`VaCuusModelLayout.h:70-76`), and both readers agree
(`VaCuusDataVariable.cpp:178`, `VaCuusWriteRouter.cpp:318-341` — `FindAuthoredNameStringByValue`).

**So `num()` on an enum leaf is `NaN`, and indexing an array with it is a bug.** Every
snippet in Tasks 16 and 17 below that does `num('…​.Category')`, `num('…​.Class')`,
`num('…​.Mount')` or `num('…​.State')` and indexes a name array is **wrong as written** —
read the leaf with `str()` and switch on the name. The mapping is:

| Leaf | Values that arrive | Note |
|---|---|---|
| `Slots[i].Category` | `"Main"` `"Second"` `"Bay"` `"Shield"` | |
| `Slots[i].State` | `"Filled"` `"Empty"` `"NoSlot"` | `SlotCard` wants lowercase |
| `Turrets[i].Class` | `"Railgun"` `"Ballistic"` | |
| `Turrets[i].Mount` | `"Bow"` `"Stern"` | |
| `Turrets[i].State` | `"Ready"` `"Reload"` `"Repair"` `"Destroyed"` | `ItemCard`'s union has **no `repair`** — map `Repair` → `'reload'` |

A `bool` is a real boolean: `Sections[0].bPowered` → `true`, `typeof === "boolean"`. Use
`bool()`, never `num()`.

Pinned by the test `Demo2d6.Model.EnumsCrossAsNames`, which fails loudly if this contract
ever changes.

**2. A read before the first push returns the DEFAULT STRUCT, not nothing.** At module
scope `Ship.Name` already answers `"AKIRO"` — a C++ default, not simulation output — while
`Slots.size` is 0 and `Slots[0].Category` is `null`. **A reader must not treat "the model
answered" as "the simulation has run"**; gate on the `*Revision` fields, which start at 0
and only move once a step has changed something.

- [ ] **Step 2: Drive the radar blips from rAF**

Add to `main.tsx`'s pump — a pool of pre-created elements moved by transform, never created or destroyed per frame:

```tsx
import { count, num } from './model';

const BLIP_POOL = 32;
const blipEls: (any | null)[] = new Array(BLIP_POOL).fill(null);

function pumpBlips() {
    const n = Math.min(count('Contacts'), BLIP_POOL);
    for (let i = 0; i < BLIP_POOL; i++) {
        if (!blipEls[i]) blipEls[i] = document!.getElementById(`blip-${i}`);
        const el = blipEls[i];
        if (!el) continue;
        if (i >= n) {
            if (el.style.opacity !== '0') el.style.opacity = '0';
            continue;
        }
        const x = 150 + num(`Contacts[${i}].X`) * 130;
        const y = 85  + num(`Contacts[${i}].Y`) * 70;
        const next = `translate(${x.toFixed(1)}px, ${y.toFixed(1)}px)`;
        // One write per element per frame, and only when it differs.
        if (el.getAttribute('data-t') !== next) {
            el.setAttribute('data-t', next);
            el.style.transform = next;
        }
        if (el.style.opacity !== '1') el.style.opacity = '1';
    }
}
```

Call `pumpBlips()` from `pump()` when the screen is `turrets`, and drop the cached
wrappers whenever the screen changes:

```tsx
subscribe('ui', 'blips.reset', () => blipEls.fill(null));
```

That line is not optional. A screen change re-renders the tree under the mount, and the
never-throw contract makes every stale wrapper answer null/false from every member with
**no error and no log line anywhere** — the blips would simply stop moving and nothing
would say why.

## Beads to file against VaCuus (not fixed here)

1. `vacuus dev` ignores `--devui-dir` — `runDev` hardcodes `DEVUI_ROOT`
   (`Web/packages/cli/lib/build.mjs:110-118`), so watch mode cannot serve a consumer
   project. `runBuild` already takes the option; `runDev` needs the same two lines.
2. `Web/packages/cli/template/app.rml.tpl:8` emits `src="<app>/<app>_bundle.js"`,
   which doubles the directory and silently yields a styled HUD with no behaviour.
3. `Content/DevUI/M5Hud/vacuus-base.rcss:13-14` and `docs/buyer/gotchas.md:23-27` both
   state that `transition: opacity 0.3s ease-in-out;` works. It parses to nothing and
   drops the whole declaration.
4. `box-shadow` renders an opaque white rectangle and forces a publish every frame;
   the docs only say it is not animatable. Either implement `SaveLayerAsTexture` or
   refuse the property with a named warning.
5. `mask-image` is a silent no-op with no warning at all.
6. `docs/buyer/rcss-matrix.md` omits `@font-face` from the at-rule list and never
   mentions `var()`/custom properties, which are fully implemented.
7. There is no public C++ font-loading API; a consumer project's only route to its own
   faces is `@font-face` (Task 1 establishes whether that route works).
